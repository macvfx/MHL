# 3.0.2 Build 64 — CopyTrust, Drop Verify and Folder Copy Compare — beta

2026-10-21 · One release carries three apps, all at 3.0.2 build 64, so each app's update check sees one version. It includes everything in
3.0.2 build 63 — see [RELEASE-NOTES-3.0.2-b63.md](RELEASE-NOTES-3.0.2-b63.md).

- **New Folder in destination pickers.** The Finder panel behind the **Dest** button in Volumes had no New Folder button, so a destination
  folder could not be made there. It now has one, as do the batch destination picker and Drop Verify's "where to save artifacts" picker.
  The **Source** panel deliberately does not: a source is a card, drive or folder that already exists.
