# 3.0.2 Build 67 — CopyTrust, Drop Verify and Folder Copy Compare — beta

2026-10-22 · One release carries three apps, all at 3.0.2 build 67, so each app's update check sees one version. It includes everything in
3.0.2 build 66 — see [RELEASE-NOTES-3.0.2-b66.md](RELEASE-NOTES-3.0.2-b66.md).

**CopyTrust**

- **Declare Off Site is in the Preset menu.** "Working away from the facility? Declare Off Site…" was a permanent line under the window whenever a preset
  with drives was loaded and nothing was missing, so an operator working in house, or over a VPN with the drives mounted, saw it on every card. It is now
  **Preset ▸ Declare Off Site…**, offered only when a preset that names drives or a project list is loaded, nothing is missing, and off site is not already
  declared. The orange launch-check banner and the *Working off site* strip with **End Off Site** are unchanged.
