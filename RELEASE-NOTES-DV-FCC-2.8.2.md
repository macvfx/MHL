# Drop Verify and Folder Copy Compare 2.8.2 Build 22 — beta

2026-09-21 · Drop Verify and Folder Copy Compare only. CopyTrust is unchanged at 2.8.5 build 26.
Not to be confused with CopyTrust 2.8.2 (Interface Size) — the apps no longer share one version.

BETA. Test on media you can afford to lose, and keep a separate verified backup made by other
software — Archiware P5 or equivalent.

## Settings, laid out like CopyTrust's

Settings in both apps now lists its tabs down the left side, the way CopyTrust 2.8.5 does. CopyTrust
2.8.4 showed why: built with a newer version of Apple's developer tools, its row of tabs across the
top was drawn as one tab with every label printed over the others. These are the first builds of
Drop Verify and Folder Copy Compare made with those tools, so they get the same layout before the
same thing can happen to them.

- **Drop Verify:** Outputs, Exclusions, External Codecs and a new **About** tab, under a
  **Drop Verify Settings** title, with the version and build beside Done.
- **Folder Copy Compare:** Exclusions, Scan Options and a new **About** tab, with the version and
  build at the bottom of the Settings window.

Nothing about verification, hashing, manifests, comparison or copying changed.

## What to test

1. Open Settings in each app and visit every tab from the list on the left. Each should open,
   and nothing should be cut off.
2. Check the About tab and the version line at the bottom agree with Help or About in the menu.
3. Change a setting, close Settings and reopen it — the change should still be there.
